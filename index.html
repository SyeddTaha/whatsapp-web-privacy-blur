Core Features

Blur Exactly What You Need

Six granular controls let you hide precisely the right content. Toggle any combination from the popup.

MSG

Messages

Incoming and outgoing message bubbles blurred until you hover to read them.

PRV

Previews

Sidebar timestamps and last-message text hidden so shoulder-surfers see nothing.

MED

Media

Image and video thumbnails inside chat are blurred until deliberately revealed.

NAM

Names

Contact and group titles in the list, chat header, and reply panels stay hidden.

AVT

Avatars

Profile photos across the list, headers, and group identity all covered.

INP

Input Field

Composer text blurred while typing, with customisable blur strength in the popup.

Install

Set Up In One Minute

No Chrome Web Store required. Load it directly from source in four quick steps.

1
Download the extension

Click Download ZIP above and save the archive anywhere on your machine.

2
Unzip the folder

Extract the contents so you have a plain folder with the extension files.

3
Load in Chrome

Navigate to chrome://extensions, enable Developer mode, click Load unpacked and select the folder.

4
Open WhatsApp Web

Go to web.whatsapp.com and click the extension icon in your toolbar to control blur settings.

Privacy First

Local, Lightweight, No Tracking

Everything runs in your browser. Nothing ever leaves your machine.

NO

Zero Analytics

No telemetry, no event tracking, no third-party SDKs. The extension doesn't know you exist.

NET

No External Calls

The extension makes zero network requests beyond what WhatsApp Web itself needs.

SYN

Local Settings

Your toggle preferences are saved in chrome.storage.sync, synced to your Google account and never to our servers.

OSS

Fully Open Source

Every line of code is public on GitHub. Audit it, fork it, and contribute under the MIT license.
